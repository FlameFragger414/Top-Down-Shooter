# Neon Miami

A top-down, one-hit-kill massacre game in the Hotline Miami mould, built for Unity 6
(6000.6.0f1) with URP and the new Input System.

Press **Play** on any scene. The whole game builds itself at runtime from
`Assets/Scripts/Core/Boot.cs` — there is nothing to wire up in the inspector, and no
prefabs to keep in sync.

## Controls

| Input | Action |
|---|---|
| `WASD` | Move |
| Mouse | Aim |
| `LMB` | Attack / fire |
| `RMB` (hold) | Scope in, on weapons that have a scope |
| `F` | Throw current weapon |
| `E` | Pick up weapon, or execute a downed enemy |
| `1`-`5` / mouse wheel | Select inventory slot |
| `G` | Drop the weapon in the current slot |
| `Shift` / `Space` | Dash |
| `R` | Restart the floor instantly |
| `Enter` | Confirm on menus |

## Scoping

You cannot look through a scope in a top-down view, so scoping is built as the thing the
view actually allows: hold `RMB` and the camera runs down your sightline instead of sitting
on you. Concretely it does four things at once.

- The camera lead cap goes from 3.6 units to the weapon's `scopeLead` — 13 for the sniper —
  and the follow strength goes 0.34 to 0.9, so you see far down the barrel.
- Orthographic size grows by the weapon's `scopeZoom`, pulling the framing back.
- Spread drops to 22 percent of the weapon's normal cone.
- You move at 45 percent speed, and the vignette closes in.

A red laser runs from the muzzle to the first wall or body it meets, and brightens when it
is resting on somebody. Dashing cancels the scope.

Scoped weapons: sniper (`scopeZoom` 3.4, lead 13), assault rifle (1.3 / 7), grenade
launcher (1.2 / 7), machine gun (1.1 / 6.5), silenced pistol (0.9 / 5.5), revolver
(0.8 / 5.5). Everything else has `scopeZoom` 0 and ignores the button. Give any weapon a
scope by setting those two fields in `WeaponDB`.

## Inventory

Five slots. `1`-`5` picks one directly, the mouse wheel cycles. An empty slot means fists,
so slot switching doubles as a way to go melee. `E` puts a pickup in the first free slot and
equips it; with all five full it swaps out whatever is in your hands and drops that on the
floor. Picking up a gun you already carry tops that slot up instead of taking a second slot.
`G` drops the current one, `RMB` throws it and empties the slot, and dying scatters all five.

Ammo lives with the slot, so a half-empty shotgun stays half empty while you use something
else. The bar along the bottom shows each slot's icon and round count.

## Weapons

Melee: fists, bat, pipe, knife, katana.

Guns: pistol, silenced pistol, revolver, twin pistols, SMG, uzi, assault rifle, machine
gun, minigun, sniper, shotgun, auto shotgun, double barrel, grenade launcher, rocket
launcher, flamethrower.

Four have their own mechanics rather than just stats. The **minigun** spins up for 0.55 s
before the first round leaves the barrel. The **sniper** pierces — one shot goes through
everyone in the line. The **rocket launcher** and **grenade launcher** detonate on impact
and kill everything inside 3.4 / 2.6 units, including you. The **flamethrower** sprays
short-lived fire that passes through bodies.

Pickups are weighted by `WeaponDef.rarity`. Every generated floor is also guaranteed two
explosive spawns (`'R'`), four ammo crates (`'a'`) and three medkits (`'h'`), on top of
`5 + floor/2` random guns and four melee weapons. Enemies drop whatever they carried.
Picking up a gun you already hold tops up its ammo instead of swapping.

## Difficulty

The player has 5 hit points (8 with the Pig mask) and a 1.4 s invulnerability blink after
each hit. Medkits restore 2. Enemies fire with 2.4x their weapon's spread plus 4 degrees,
take 0.8-1.3 s to react to spotting you, cannot shoot at all in the first 1.8 s of a floor,
see 9.5 units through a 52-degree cone that only widens to 97 degrees once chasing, and
number `3 + 1.2 x floor`. Tune all of it in `EnemyDB`, `Weapon.FireGun`, and `PlayerCtrl`.

Getting hit shakes the camera by 0.18 trauma — deliberately much softer than gunfire, which
runs 0.1 to 0.9 depending on the weapon.

## The loop

Kill everyone on the floor, then walk to the exit marker. Enemies die in one hit; you get three. `R` restarts immediately — dying is meant to cost you three
seconds, not a run.

Six masks, each with one perk: Rooster (speed), Owl (see enemy vision cones), Tiger
(longer, always-lethal melee), Wolf (start with a knife), Pig (survive one hit), Rabbit
(dash twice as often).

Floor 1 is hand-authored (`Assets/Scripts/Level/Levels.cs`). Every floor after it is
generated by a BSP room-and-corridor pass that scales enemy count and difficulty with
depth, so the game does not run out.

## Art and audio

Both are generated, and both are original — no assets from any commercial game are
used or shipped here.

**Sprites** are produced by `Tools/gen_art.py` into `Assets/Resources/Art/`, together
with hand-written `.meta` files that pin the import settings (Sprite, 32 PPU, point
filter, uncompressed). Regenerate them with:

```bash
python Tools/gen_art.py
```

`Tools/pixelkit.py` is the drawing kit (canvas, shapes, dithering, outlines, palette),
`Tools/font5x7.py` is the bitmap font.

**Sound** is synthesised at runtime in `Assets/Scripts/Audio/Synth.cs`. Every gun has its
own voice, plus death screams (three formant-glide variants), bone crunch on melee kills,
rounds whizzing past your head, footsteps, ammo and heal chimes, a combo blip that rises
with the multiplier, a clear fanfare and a death sting. The music is a generated synth loop
— kick, snare, hats, saw bass, arpeggiated lead with feedback delay — built per floor.
There are no audio files in the project.

### Swapping in your own art

Everything loads by filename through `Art.Get("name")`, which reads
`Assets/Resources/Art/<name>.png`. Drop a replacement PNG over any of them — same
filename, any resolution — and the game picks it up with no code changes. Characters
and weapons must face **up** (+Y); the code only ever applies a Z rotation.
`Assets/Scripts/Editor/ArtImport.cs` forces the correct import settings on anything
added to that folder.

## Enter Play Mode Options

This project has Enter Play Mode Options on with **Reload Domain disabled**, so statics
survive between Play sessions. `Assets/Scripts/Core/Statics.cs` wipes every static the game
owns on `SubsystemRegistration` — most importantly the sprite cache, because sprites made
with `Sprite.Create` are destroyed when Play mode ends. Any new static collection or
singleton must be reset there too.

Reload Scene is left **enabled**: `Boot` clears the loaded scene when it starts, and scene
reload is what puts it back for the next run.

## Cameras

Two cameras: the world camera and the HUD camera. The HUD camera is a URP **Overlay** on the
world camera's `cameraStack` — as a Base camera it would clear the frame and erase the world,
leaving only UI on a blank background. Overlay cameras report no usable `aspect` and their
`ScreenToWorldPoint` is unreliable, so `HUD` lays itself out from `Screen.width/height`.

## Checks

`Neon Miami ▸ Run Smoke Test` (or `-executeMethod Neon.EditorTools.NeonSmokeTest.Run`)
verifies that every sprite the game asks for exists and imported correctly, and that
the intro map plus 24 generated floors are all fully connected — exit and every enemy
reachable from the player spawn.
